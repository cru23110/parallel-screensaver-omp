# Esquema del informe (borrador de estructura, no el informe final)

Esto es solo un esqueleto para que cada quien sepa dónde va su parte. El documento final
se arma con el formato UVG (carátula, fuentes, márgenes, etc.) en la Fase 4 — ver
`PLAN.md` en la raíz del proyecto (fuera de este repo) para fechas y responsables.

- [ ] Carátula
- [ ] Índice
- [ ] Introducción
- [ ] Antecedentes
- [ ] Cuerpo del informe
  - [ ] Versión secuencial: diseño y decisiones
  - [ ] PCAM (Partición, Comunicación, Aglomeración, Mapeo)
  - [ ] Versión paralela: qué se paralelizó y cómo
  - [ ] Sincronía / protección de memoria compartida usada
- [ ] Resultados: speedup y eficiencia (tabla + gráfica, mínimo 10 mediciones por prueba)
- [ ] Optimización extra (si se hace alguna) y su speedup comparado
- [ ] Conclusiones y recomendaciones
- [ ] Referencias bibliográficas (mínimo 3)
- [ ] Anexo 1 — Diagrama de flujo (args, ingreso de datos, programación defensiva,
      secciones paralelas, sincronía, despliegue de resultados)
- [ ] Anexo 2 — Catálogo de funciones (entradas, salidas, descripción)
- [ ] Anexo 3 — Bitácora de pruebas (mediciones, speedups/eficiencia, capturas)
